# Do not make changes in this repository

This repository is **generated output**, not source. Its files are overwritten wholesale by `scripts/publish-github-pages.sh` in the source repository, so any edit committed here is destroyed the next time the site is published, without warning.

**The source repository is [ec8or/osa-website](https://github.com/ec8or/osa-website).** Every change to the One Step Ahead website belongs there.

If you have been asked to change the OSA website and you are in this repository, you are in the wrong place. Say so, and ask to be pointed at `ec8or/osa-website` instead. Do not edit these files, do not open a pull request here, and do not try to reproduce the change in both places.

This repository exists only to serve <https://ec8or.github.io/osa-prototype/>, the pre-Cloudflare review site. It is due to be retired now that the source repository deploys and generates its own preview links.
