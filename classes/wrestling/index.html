Takedowns and control

Decide where the fight happens

Develop the wrestling skills that let you dictate position in MMA and submission grappling.

Learn reliable entries, finishes, defence and mat control, then apply them through purposeful drills and rounds.

Who this class is for

The class is useful for MMA athletes, NoGi grapplers and newcomers who want to build a strong base. Techniques are broken down so they can be learned without a wrestling background.

What to expect

Wrestling is physically demanding, but the class is technical first. Drills build from movement and position into controlled resistance so you can learn to apply each skill safely.

How it fits your week

Use Friday submission wrestling to develop the link between takedowns, control and submissions, then test those skills across MMA and NoGi sessions.

What you’ll work on

  • Stance, movement and takedown entries
  • Finishes, sprawls and re-attacks
  • Top pressure, rides and stand-ups
